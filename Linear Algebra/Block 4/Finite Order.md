A matrix $A$ has finite order $n$ if $A^n=I$ for some $n$ 
$n$ is an integer


The matrix that rotates 90 degrees has an order of 4 as it takes 4 rotations to reach the identity matrix

If a matrix $A$ has finite order $n_1$ then any matrix similar to $A$ also has the order $n_1$

Any matrix with infinite order will never reach I when raised to an integer power

Example a rotation matrix that rotates by an irrational value Ex: $\sqrt{2}$
