The set $W$ is a subspace of $V$ if $W$ is a subset ($V$ contains all of $W$) and $W$ is a vector space as well.

### How to check if a subset is actually a subspace
- Must be closed under addition
- Must be closed under scalar multiplication
- It contains zero

### Span as a subspace
- Spans are closed under addition and multiplication
- and they contain 0
