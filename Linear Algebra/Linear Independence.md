$Ax=0$ always has a solution x=**0**. A solution always exists trivial solution. 
Are there other solutions?

$V_1...V_n \in V$, **0** is in a combo of $V_1...V_n \in V$
Can **0** be written as a linear combo in a non-trivial way?
Find $Ax=0$, where $x\neq0$. This makes the list linearly dependent

If any vectors are combinations of other vectors then it has a solution
Ex with $V_1...V_3$ if $V_1+V_2=V_3$ then a solution could be $[1,1,-1]$

A list is linear independent if the only way to get $x=0$ is the only solution to $Ax=0$

### Linear Dependence Proposition
$\{v_1;...;v_n\}$  is linearly dependent is one of the vectors is in the span of the others
