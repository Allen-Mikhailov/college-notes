$y\prime(t)=p(t)y(t)+q(t)$
$p(t)$ is variable interest rates
$q(t)$ is rate of deposits
Mathematically introduce an operator
$Ly=\frac{dy}{dt}-p(t)y(t)$
$Ly=q(t)$
$y(0)=100$
An operator turns one function into another via a rule
$L$ has to satisfy certain properties
If $y_1,y_2$ are functions
$L(y_1+y_2)=(y_1+y_2)\prime-p(t)(y_1+y_2)$
$=(y_1\prime-py_1)+(y_2\prime-py_2)$
=$L(y_1)+L(y_2)$
It satisfies addition
$L$ is a LINEAR Operator (it respects addition and scalar multiplication)
